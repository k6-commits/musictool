## v2 の方向性: Night Studio

v1 のフィードバック「テキストが多い」を受けて、**文字は 1 行まで、操作は鍵盤・つまみ・アイコンで**という方針に変えた。

- 説明文をなくし、状態は図と色と形で見せる（例: 書き出しの置き方は「1 小節目にドロップ」の図）
- 音楽アプリらしい部品を使う: 縦の鍵盤（歌うと鍵盤が光る）、つまみ（SCALE / GRID）、フェーダー（FAST ↔ STABLE）、トランスポート（REC / PLAY）
- 技術的なラベルは音楽アプリで一般的な短い英語（BPM / KEY / SCALE / GRID / REC）、操作の言葉は短い日本語

| 名前 | 色 | 用途 |
|---|---|---|
| 地 | `#08090C` | 画面の背景 |
| 面 | `#111318` | カード・ボタン・シート |
| 鍵盤 | `#D4D8DF` / `#15181E` | 白鍵 / 黒鍵 |
| 文字 | `#F4F5F7` / `#9BA3B0` | 本文 / 補足 |
| 声 | `#FF6B4A` | 声の線・REC・光る鍵盤・主ボタン |
| 音符 | `#56C2FF` | ノート・つまみ・選択中 |
| 要確認 | `#FFC24A` | 自信のない音（破線と「!」を併用） |
| 接続 | `#45E0A2` | 接続中・完了・プライバシー |

文字: Space Grotesk（音名・数字・英語ラベル）＋ Noto Sans JP（日本語）

## 画面遷移（v2）

```
はじめて:   はじめる（マイク許可）→ 声域（スキップ可）→ 録音
              └ 拒否 → マイクオフ（設定アプリへ）

いつも:     ライブラリ →（REC）→ 録音 →（停止）→ 編集 →（共有）→ 書き出し → 完了 → ライブラリ
                                              └ ! をタップ ⇄ 確認シート（鍵盤で選ぶ）

DAW 連携:   ライブラリ → DAW → QR → ライブ接続 → 録音
設定:       ライブラリ → 設定（声域 → 声域チェック）
```

## UX の原則

1. 文字は 1 行まで。説明が必要なら図・アイコン・色で見せる
2. 操作は鍵盤・つまみ・アイコン（音楽アプリの道具の形）
3. 状態は色と形の両方で示す（要確認 = 黄色＋破線＋「!」）
4. 主なボタンは親指の届く下側。タップ領域は 44px 以上
5. 30 秒で最初の 1 音（初回はライブラリを飛ばして録音へ）
6. 自動補正は何度でも戻せる（つまみで調整、直したら「元に戻す」）

## 動き

| 場面 | 動き |
|---|---|
| 画面 | 320 ms、フェード＋少し上へ |
| シート | 280 ms、下から |
| REC ● → ■ | 180 ms。録音中は外側が呼吸する |
| カウント | 拍（♩）に同期して数字を拡大 |
| 波形 → ノート | 1.5 s。ノートは 50 ms 間隔で出現 |
| ノート移動 | 250 ms（つまみ操作に追従） |

基本のイージングは `cubic-bezier(.2, .8, .2, 1)`。「動きを減らす」設定では移動をなくす。
