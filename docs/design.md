## 方向性: 夜のスタジオ（Night Studio）

暗い藍色の地に、**声 = コーラルの線**、**音符 = 空色のブロック**。「声が音符に変わる瞬間」を、すべての画面で共通の主役にする。

| 名前 | 色 | 用途 |
|---|---|---|
| 地 | `#0E1016` | 画面の背景 |
| 面 / 面 2 | `#161922` / `#1E222D` | カード・シート / その中の要素 |
| 線 | `#2B3040` | 枠・区切り・選択中の背景 |
| 文字 / 文字 2 | `#F3F4F7` / `#AEB5C2` | 本文 / 補足 |
| 声 | `#FF7A59` | 声の線・録音・いちばん大事なボタン |
| 音符 | `#6CC4FF` | ノート・確定した状態 |
| 要確認 | `#FFC657` | 自信のない音（必ず破線と「!」を併用） |
| 接続 | `#5EE0A0` | 接続中・プライバシーの表示 |

- 文字: Space Grotesk（音名・テンポ・時間などの数字）＋ Noto Sans JP（見出し・本文）
- 声と音符の色は、色相だけでなく明るさも変えて区別できるようにする

## 画面遷移

```
はじめて:   ようこそ → マイクの準備 → 声域チェック（スキップ可）→ 録音
              └ 許可しない → マイクがオフ（設定アプリへ案内）

いつも:     ホーム → 録音 →（停止）→ 編集 → 書き出し → 完了 → ホーム
                              └ 要確認ノートをタップ ⇄ ノート確認シート

DAW 連携:   ホーム → DAW とつなぐ → QR でペアリング → 接続中 → 録音
設定:       ホーム → 設定（声域 → 声域チェック）
```

## UX の原則

1. **30 秒で最初の 1 音**: 初回はホームを飛ばして録音画面へ直行する
2. **待たせない**: 解析中の待ち画面は作らず、編集画面の中で「波形がノートに変わる」アニメーションとして見せる
3. **間違いは目立たせて、1 タップで直す**: 自信のない音は破線と「!」で示し、候補（おすすめ / 半音下 / 半音上）から選ぶ。直したらすぐ「元に戻す」を出す
4. **自動補正は何度でも戻せる**: スケール吸着とタイミング補正はスライダー。元の解析結果は消さない
5. **安心**: 登録不要。録音と解析は端末の中だけで行う
6. **片手で使える**: 主なボタンは画面の下半分に置き、タップ領域は 44px 以上

## 動き

| 場面 | 動き |
|---|---|
| 画面の移動 | 320ms、フェード＋少し上へ |
| シートを開く / 閉じる | 280ms / 200ms、下から |
| 録音ボタン ● → ■ | 180ms。録音中は外側がゆっくり呼吸する |
| カウントイン | 拍に合わせて数字を拡大 |
| 解析 → ノート | 波形が縮み、ノートが 50ms 間隔で出現 |
| スライダー → ノート移動 | 250ms |
| 「動きを減らす」設定 | 移動をなくし、表示の切り替えだけにする |

- 基本のイージングは「素早く出て、ゆっくり止まる」`cubic-bezier(.2, .8, .2, 1)`
- 拍・録音開始・ノート確定には軽い振動を付ける

## 仕様への反映

- 中央のドの表記に C5（FL Studio）を追加した（SPEC F-12）。DAW によって C3・C4・C5 の 3 通りがあるため
- 書き出しの既定は「MIDI ＋ 声の WAV」
- 解析の処理時間の目標（SPEC 9 章）はそのままで、その間を編集画面のイントロアニメーションで見せる
